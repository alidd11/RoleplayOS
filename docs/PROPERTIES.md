# Properties

Property definitions support purchase or rent prices, interior templates, garage and furniture capacity. Acquisition checks availability and character ownership and uses the configured economy price. Holdings distinguish owner and tenant and store stable keyholder character IDs.

Interiors are ServerStorage templates cloned only when entered. Occupancy is counted and empty interiors unload after a delay. Production maps must supply secure entrance volumes, interior allocation and rejoin recovery. Primary residence and periodic rent collection fit the existing holding contract.
