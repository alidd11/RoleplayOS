# Jobs and applications

Configuration defines public and application jobs, base wages and server-side task rewards. Employment records belong to characters. Shifts are temporary server state, prevent concurrent clock-ins and require server-issued task proof with a minimum activity interval; this is the anti-AFK foundation, not a complete minigame.

Applications validate configured questions and allowed choices, prevent active duplicates, enforce rejection cooldowns and expose applicant-safe DTOs. Status changes are audited. Production review endpoints must first resolve staff permissions; private reviewer notes must never enter applicant DTOs.
